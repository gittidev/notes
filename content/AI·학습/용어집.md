> 항공(드론) 영상 분할 모델을 만들면서 자주 쓰는 말을 한 줄씩 풀어 둔다.

## 1. 평가·실험 설계
- **LOSO (Leave-One-Site-Out, 사이트 하나 빼고 채점)**: 라벨이 있는 사이트가 여러 곳일 때, 한 사이트를 통째로 빼고 나머지로 학습한 뒤 뺀 사이트에서 점수를 내는 방식. 「처음 보는 사이트에서 얼마나 맞나」를 정직하게 잰다. 뺄 사이트를 바꿔 가며 반복하면 사이트마다 점수가 나온다. → [[데이터 분할 원칙]]
- **교차 사이트 채점**: 한 사이트로 학습한 모델을 다른 사이트에 적용해 채점하는 것. 학습 사이트가 하나뿐일 때의 LOSO 축소판.
- **검증 블록(val block)**: 사이트를 격자 블록(예: 4×4)으로 나눠 몇 개를 학습에서 빼 두고 점수용으로만 쓰는 칸. 같은 사이트 안이라 「옆 땅」 점수에 가깝다. 사이트 밖 점수보다 늘 좋게 나온다.
- **모델 선택용 구역과 최종 채점 구역**: 「몇 번째 에폭이 제일 좋은가」는 선택용 구역으로만 고르고, 최종 채점 구역은 마지막에 한 번만 본다. 채점 구역으로 에폭을 고르면 점수가 낙관적이 된다.
- **공간 누수 차단(val-guard)**: 학습 타일의 창이 검증 블록에 닿으면 그 타일을 뺀다. 모델이 검증 땅을 「곁눈질」하지 못하게 하는 규칙.
- **칸 단위 비율 오차(%p)**: 일정 크기의 칸마다 「예측한 클래스 비율 − 정답 비율」의 절댓값을 내고 평균한 것. 결과를 칸 단위 비율로 쓸 때 맞는 지표다. 치우침(bias)은 부호를 살린 평균(+면 과대, −면 과소).
- **IoU / mIoU**: 픽셀 단위로 「겹친 부분 / 둘 중 하나라도 칠한 부분」. 클래스별 IoU의 평균이 mIoU. 지도 모양이 맞는지 본다. 비율만 맞히는 모델은 mIoU가 낮아도 칸 비율 오차는 괜찮을 수 있다. → [[평가 지표 IoU mIoU]]
- **시드(seed)**: 난수 출발점. 같은 설정도 시드가 다르면 점수가 조금 다르다. **시드 3개 평균**으로 비교하고, 범위가 겹치면 「차이 없음」으로 본다.
- **에폭(epoch)**: 학습 데이터를 한 바퀴 다 보는 단위. 데이터가 커지면 에폭 수를 줄여도 된다.
- **연기 시험(smoke test)**: 1 에폭·타일 몇 장으로 끝까지 돌려 코드 경로만 확인하는 것. 숫자 비교용이 아니다.
- **MLflow 실험 / 런**: 실험(experiment) = 비교 묶음 폴더, 런(run) = 학습 한 번. 설명란에 무엇·왜·데이터·결과·결론을 적어 두면 나중에 찾기 쉽다.

## 2. 모델 구조
- **U-Net**: 픽셀마다 클래스를 찍는 분할 네트워크. 앞부분(인코더)이 패턴을 뽑고 뒷부분(디코더)이 픽셀 크기로 펼친다. → [[백본과 디코더]]
- **인코더 / 백본(backbone)**: 모델의 「몸통」. 영상에서 특징을 뽑는 부분. ResNet34, ConvNeXt 등 사전학습된 것을 가져다 쓴다.
- **사전학습(pretrained) / 미세조정(fine-tuning)**: 남이 큰 데이터로 먼저 가르쳐 둔 가중치를 가져와(사전학습) 내 라벨로 조금 더 가르치는 것(미세조정). ImageNet 사전학습 = 일반 사진 수백만 장.
- **기반 모델(foundation model, GFM)**: 위성·항공 영상 수억 장으로 미리 학습한 큰 모델(Prithvi·Clay·TerraMind 등). 쓰기 전에 벤치마크 신뢰도와, 학습 영상과 내 영상의 해상도 차이를 먼저 확인한다.
- **DINOv2**: Meta의 범용 시각 특징 모델. 영상 조각(14 px 토큰)마다 숫자 벡터(ViT-S 기준 384개)를 낸다. 라벨 없이 배워서 「무늬·질감의 의미」를 담고 있다. 라벨이 적을 때 도움이 된다.
- **특징(feature) / 토큰**: 모델이 영상에서 뽑은 숫자 벡터. 토큰 = ViT가 영상을 격자로 자른 한 칸.
- **PCA(주성분 분석)**: 숫자 수백 개를 가장 크게 달라지는 방향 몇 개로 줄이는 방법(예: 384 → 32). 축은 데이터를 보고 정한다. 그래서 **데이터셋마다 따로 맞추면 축이 달라진다.** 학습 때 맞춘 PCA를 파일로 저장해 추론에도 그대로 쓴다.
- **LoRA**: 큰 모델의 가중치 일부에 작은 보정 행렬만 붙여 싸게 미세조정하는 방법.
- **SAM(Segment Anything)**: 클릭한 자리의 「덩어리」를 잘라 주는 모델. 그게 무엇인지는 모르고 「어디까지가 한 덩어리인지」만 안다. **자동 마스크(AMG)** = 클릭 없이 영상 전체를 덩어리로 쪼개는 모드. 가늘고 성긴 대상에서는 잘 안 된다.

## 3. 손실 함수 (모델이 무엇을 맞추려 애쓰는가)
- **CE(교차 엔트로피)**: 픽셀마다 「정답 클래스 확률을 높여라」. 기본. → [[크로스엔트로피]]
- **Dice**: 클래스별 겹침 비율을 올려라. 작은 클래스가 묻히지 않게. → [[손실 함수]]
- **clDice**: 가늘고 이어진 구조(혈관·도로·물길)가 끊기면 벌점을 준다.

## 4. 데이터·증강·학습 방법
- **증강(augmentation)**: 학습 타일을 뒤집기·회전·색 바꾸기로 부풀려 모델이 외우지 못하게 하는 것. → [[데이터 증강]]
- **히스토그램 정합 증강(RHM)**: 타일의 색 분포를 다른 타일의 분포에 맞추는 증강. 「그날 그 장소의 색」을 외우지 않게 한다. 기준 분포를 같은 장소에서만 뽑으면 효과가 없다. 여러 장소를 섞을 때 쓴다.
- **반지도 학습(semi-supervised)**: 라벨 없는 타일도 학습에 쓰는 방법. 모델이 스스로 낸 답이 흔들리지 않게 가르친다.
- **자기지도(self-supervised)**: 라벨 없이 영상만으로 특징을 배우는 사전학습.
- **능동학습(active learning) / 불확실도 지도**: 모델이 헷갈리는 곳을 지도로 내서 「다음에 어디를 칠하면 가장 도움이 되나」를 고르는 것.
- **모델 초안 → 고치기 루프**: 모델 예측을 먼저 깔고 사람은 틀린 데만 고치는 작업 방식(pre-labeling). → [[라벨링 방법론]]
- **부분 라벨(칠한 칸만)**: 칠한 픽셀만 정답으로 쓰고 안 칠한 곳은 무시(ignore index)하는 방식. 「안 칠한 곳 = 배경」 규칙과 섞어 쓸 때 주의한다.
- **타일 / stride(보폭)**: 큰 정사영상을 512 px 조각으로 잘라 학습한다. 보폭 256 = 반씩 겹치게(타일 수 ↑), 512 = 안 겹치게. → [[패치 분할]]

## 5. 라벨링
- **기본값 채움(안 칠한 곳 = 배경)**: 다 끝낸 구역 안에서 안 칠한 픽셀은 자동으로 배경 클래스로 친다. 넓은 배경을 일일이 칠할 필요가 없다.
- **지면 층 / 덮개 층**: 바닥 종류와 그 위를 덮은 것을 다른 층으로 라벨한다. 덮개가 있으면 덮개 값이 보이고, 지면은 그 아래 그대로 남는다.
- **완료 표시 / 검수**: 완료 = 그 구역 라벨이 끝났다는 표시(학습·채점에 넣는 조건). 검수 = 다른 사람이 확인하는 단계.
- **피복률(피도) vs 밀도**: 피복률 = 위에서 봤을 때 식물이 덮은 면적의 비율. 밀도 = ㎡당 줄기·개체 수. 위가 다 덮이면 밀도가 올라도 피복률은 100%에서 멈춘다(포화).
- **조각(슈퍼픽셀, superpixel) / SLIC**: 색이 비슷한 이웃 픽셀을 작은 덩어리로 묶은 것. 「비슷한 조각 고르기」나 조각 단위 분류기의 단위가 된다.
- **라벨 노이즈**: 정답 자체가 틀리거나 사람마다 다른 것. → [[라벨 노이즈]]

## 6. 영상·격자
- **정사영상(ortho)**: 사진 수백 장을 지도처럼 펴서 붙인 영상. 라벨의 기준 격자가 된다. 원본 사진은 판독 보조. → [[정사영상]]
- **GSD**: 픽셀 한 칸이 땅에서 몇 cm인가. → [[GSD]]
- **DSM / DTM / CHM**: 표면 높이 / 땅 높이 / 둘의 차 = 식생 높이. 사진측량 CHM은 키 낮은(수십 cm) 식생을 잡음 속에서 놓친다. → [[DSM과 DTM]]
- **치마(skirt) 현상**: 정사영상 가장자리에서 표면 모형이 흘러내려 사진이 늘어나 붙는 줄무늬. 촬영 범위 밖이라 라벨하지 않는다. 처리 때 경계 자동 지정(auto-boundary)으로 줄인다.
- **memmap**: 큰 배열을 메모리에 다 올리지 않고 파일에서 건드린 부분만 읽는 방식. 큰 정사영상을 다루는 서버의 메모리 폭주를 막는다.
